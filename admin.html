How saving works (please read once)

This page edits a draft stored in this browser only. It cannot change the live website by itself, because a free static site has no server to save to. Publishing takes three steps:

  1. Add, edit, hide or delete events below. Your draft is saved automatically in this browser.
  2. Click Download events.js.
  3. Replace the events.js file in your site (on GitHub: open the file, or use Add file, then Upload files, and commit). The live page updates in about a minute.

Your draft lives only in this browser on this device. Clearing site data or using a different device or private window will not show it, so download events.js after any real changes. Anyone can open this page, but nobody can publish anything without access to your site files.

This browser is blocking storage, so your draft will be lost if you refresh. Make your edits and download events.js before leaving the page.
